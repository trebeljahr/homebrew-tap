# Ricos Labs Homebrew tap

Casks for [Ricos Labs](https://github.com/trebeljahr) applications.

```bash
brew tap trebeljahr/tap
brew install --cask track-your-time
```

| Cask | What it is |
| --- | --- |
| `track-your-time` | [Track Your Time](https://trackyourtime.dev) — open-source time tracking for billable work |

The casks here are written by the `desktop-manifests` workflow in
[trebeljahr/trackyourtime](https://github.com/trebeljahr/trackyourtime) when a
release is published. Edit them there, not here.
